# CNAB Retorno — leitor de arquivos de retorno bancário Ferramenta web (HTML/CSS/JS puro, sem backend) para abrir arquivos `.RET` de retorno de cobrança bancária (CNAB 400 e CNAB 240) e visualizar cada campo com sua posição exata no arquivo. Todo o processamento acontece no navegador — nenhum arquivo é enviado a um servidor. ## Como usar localmente Basta abrir `index.html` em qualquer navegador. Não há build, nem dependências, nem instalação. ## Como publicar no GitHub Pages 1. Crie um repositório novo no GitHub (ex: `cnab-validator`) e suba estes três arquivos (`index.html`, `cnab.js`, `README.md`) para a branch `main`. 2. No repositório, vá em **Settings → Pages**. 3. Em "Source", selecione a branch `main` e a pasta `/ (root)`. 4. Salve. Em alguns minutos o site estará disponível em: `https://SEU-USUARIO.github.io/cnab-validator/` Alternativamente, via linha de comando: ```bash git init git add index.html cnab.js README.md git commit -m "cnab retorno validator" git branch -M main git remote add origin https://github.com/SEU-USUARIO/cnab-validator.git git push -u origin main ``` Depois é só ativar o Pages nas configurações do repositório. ## O que o sistema faz - Detecta automaticamente se o arquivo é **CNAB 400** ou **CNAB 240** (pelo tamanho predominante das linhas: 400 ou 240 colunas). - Identifica o tipo de cada registro (header de arquivo, header de lote, detalhe/segmento, trailer de lote, trailer de arquivo). - Para CNAB 240, também reconhece os segmentos de detalhe (T, U, etc.), como usado por bancos como Sicredi, Sicoob, Banco do Brasil e Itaú. - Mostra, para cada campo, a posição inicial/final, o rótulo do campo, o valor já interpretado (datas formatadas, valores em R$, código do banco traduzido para o nome, código de ocorrência traduzido) e o valor bruto como está no arquivo. - Sinaliza linhas que não têm o tamanho esperado (400 ou 240 colunas), o erro mais comum que causa falha silenciosa em sistemas como o IXC. ## Limitação importante Os layouts usados aqui seguem o **padrão Febraban genérico**. A maioria dos bancos segue esse padrão à risca no CNAB 240 (é obrigatório por norma), mas alguns campos do CNAB 400 têm pequenas variações de posição entre bancos (principalmente nas faixas de "uso da empresa" e nos códigos de ocorrência proprietários). Se um campo aparecer com valor sem sentido, vale checar o manual de especificação técnica do banco emissor daquele arquivo específico. ## Arquivos - `index.html` — interface (upload, tabela de resultados) - `cnab.js` — lógica de parsing e definição de layout dos campos - `README.md` — este arquivo
